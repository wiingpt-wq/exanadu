경로별 지원한도 계산

한도는 누적 금액 한도가 아니라 대상기간에 대한 최대 지원금액입니다. 일할로 계산하므로 같은 기간을 한 번에 신청하든 여러 번 나눠 신청하든 상한 합계는 같습니다. 그래서 신청 횟수 제한이 없어도 기간만 겹치지 않으면 과다 지원이 생기지 않습니다.

공통 정의

적용금리 r = 관리자 등록 기준금리(구간별) + 가산금리 1.00%p 구간 분할 = 행 기간 ∩ 기준금리 등록 기간 → 구간마다 r 이 하나 일수 비율 = 구간 일수 ÷ 365 (시작일·종료일 포함, 윤년도 365 고정 제안) 기준금액(고정) = 매매 180,000,000원 / 전세·월세 120,000,000원 금액 처리 = 구간별 계산값은 소수 유지, 구분별 합계에서 원 미만 절사

경로 ① 매매

산식금액 = Σ 구간 [ 대출잔액 × r × 일수/365 ] 최대지원 = Σ 구간 [ 180,000,000 × r × 일수/365 ] 지원금액 = Σ 구간 [ min(대출잔액, 1.8억) × r × 일수/365 ] ← 잔액 1.8억 초과분만 잘림

경로 ② 전세

지원금액 = Σ 구간 [ min(대출잔액, 1.2억) × r × 일수/365 ]

경로 ③ 월세 (보증금 + 월세)

보증금분 = Σ 구간 [ 보증금 × r × 일수/365 ] 월세분 = Σ 월 [ 월세 × (해당월 대상일수 ÷ 해당월 총일수) ] ← 월 중간 시작·종료는 일할 산식금액 = 보증금분 + 월세분 최대지원 = Σ 구간 [ 120,000,000 × r × 일수/365 ] 지원금액 = min(산식금액, 최대지원) ← 월세는 합계 기준으로 상한 적용

화면 표시

매입 대출이자 지원금액 = 매매 행 지원금액 합계 전월세 지원금액 = 전세 행 지원금액 + 월세 행 지원금액 최종 지원금액 = 두 금액의 합 (기간이 겹치지 않으므로 합산해도 동시 지원이 아님)

확인 요청

3차 결정 이후 남은 항목입니다.

  1. 정책서 수정본 파일. 기준금리 삭제·수정 시 신청 건 반영 정책이 추가된 수정본을 받지 못했습니다. 다시 공유해 주시면 G-04 제안안과 대조하겠습니다.
  2. 소급 하한. 분기 제한이 없어졌는데, 2차 답변의 “소급 불가”는 유지되나요? 유지된다면 대상기간 시작일을 언제까지 허용하나요? (서비스 오픈일 이후, 신청일 기준 N개월 이내 등)
  3. 지원규정 전달. 지원규정은 언제, 누가 전달하나요? 회원 화면에도 지원규정을 안내(팝업·첨부)해야 하나요?
  4. 같은 구분 기간 겹침. 대출을 2건 동시에 보유한 경우처럼 같은 구분 행끼리 기간이 겹치면 잔액을 합산해 지원하나요, 차단하나요?
  5. 기간 한도. 매매 13년, 전·월세 합산 10년 기간 한도를 시스템에서 관리하나요? 관리한다면 도입 전 지원 이력은 어떻게 이관하나요?
  6. 실제 납입이자가 산식 금액보다 적으면 실제 이자까지만 지원하나요?
  7. 부부가 모두 임직원일 때 같은 대출·계약에 대한 중복 신청은 어떻게 막나요?
  8. 주민등록번호가 포함된 증빙(가족관계증명서·등본)의 수집 근거와 보관기간은? 뒷자리 마스킹 발급으로 안내해도 될까요?
