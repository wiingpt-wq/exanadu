승인 시 한도 차감 여부미답변금액 한도는 분기 건별이므로 금액 차감은 불필요13년/10년 기간 한도 관리 여부 재질의 (A-07)
10월에 1~9월 이자 신청 가능 여부해당 분기만 가능, 소급 불가대상기간은 한 분기 안에서만 입력. 분기를 넘기면 차단신청기간 상시 개방과 함께 “해당 분기”를 무엇으로 볼지 (F-02)
전세·월세 각각 신청 가능 여부분기 내 매매·전세·월세 중 하나만. 단 구분이 바뀌면 차수를 나눠 추가 신청 (1월 월세 / 2월 전세 / 3월 매매 → 4월에 1·2·3차수)신청 1건 = 구분 1개. 동일 분기 추가 신청은 구분이 바뀐 경우만 허용, 기간 겹침 차단차수 부여 순서, 취소·반려 건 차수 처리 (F-03)
퇴사 예정 정보 확인 방법DB 저장 없음. 고객사가 발생 시마다 공유. 의료비처럼 신청기간 상시 개방신청월 제한 삭제. 퇴사자 수시 신청은 관리자가 공유 목록과 대조해 승인·반려일반 직원의 당분기 조기 신청을 막을 방법 (F-02)
차수의 의미분기 내 대출 종류 변경 시 신청 순번. 분기 첫 신청은 항상 1차수차수 = 분기별 1부터 자동 부여. 목록·관리자 화면에 대상분기·차수·구분 컬럼 추가F-03

고객사 답변의 “5p”(차수, 기준금리 입력, “7. 최대한도 기준”)는 SB87931 화면설계서 5페이지(MO화면 간지)와 맞지 않습니다. 고객사가 쓰는 별도 신청서 양식을 가리키는 것으로 보이며, 원본을 받아 화면 항목과 대조해야 합니다.

핵심 결론

답변으로 신청 단위가 “분기 × 구분(차수)”으로 확정되었습니다. 현재 화면은 한 신청서에 여러 구분을 섞어 합산하는 구조라 신청 단위부터 바꿔야 합니다.

해당 분기만 신청, 소급 불가, 신청기간 상시 개방대상기간 범위 제한 없음대상기간이 한 분기 안에 있고 종료일 ≤ 신청일인지 검증. 허용 분기 기준 확정 필요(F-02)

입사 이후 계약 건에 한하여 지원계약일·대출실행일 입력 항목 없음행별 계약일(대출실행일) 필드 추가, 입사일과 비교
본인 또는 배우자 명의 / 배우자 명의 월세 계약 시 서류 필수명의 구분 없음, 첨부 종류 구분 없음명의(본인/배우자) 선택, 배우자 선택 시 가족관계증명서·주민등록등본 필수 검증

경로별 지원한도 계산

고객사 답변: 한도는 연간·누적 한도가 아니라 분기 신청 건(차수)별 최대 지원금액입니다. 차수마다 자기 대상기간에 대해 독립적으로 계산하고, 승인 후 금액을 차감하지 않습니다.

공통 정의

적용금리 r = 기준금리(행별 값) + 가산금리 1.00%p 기준금리 출처: 회원 입력(현 답변) 또는 관리자 등록값(권장) → F-01 대상기간 = 해당 차수의 시작일~종료일, 한 분기 안 (양편 포함) 일수 비율 = 일수 ÷ 365 (윤년도 365 고정 제안) 기준금액(고정) = 매매 180,000,000원 / 전세·월세 120,000,000원 금액 처리 = 행별 계산값은 소수 유지, 차수 합계에서 원 미만 절사 금리 변경 시 = 금리가 바뀐 날짜로 행을 나눠 입력 → 행마다 r 이 하나

경로 ① 매매

산식금액 = Σ 행 [ 대출잔액 × r × 일수/365 ] 최대지원 = Σ 행 [ 180,000,000 × r × 일수/365 ] 지원금액 = Σ 행 [ min(대출잔액, 1.8억) × r × 일수/365 ] ← 잔액 1.8억 초과분만 잘림

경로 ② 전세

지원금액 = Σ 행 [ min(대출잔액, 1.2억) × r × 일수/365 ]

경로 ③ 월세 (보증금 + 월세)

보증금분 = Σ 행 [ 보증금 × r × 일수/365 ] 월세분 = Σ 월 [ 월세 × (해당월 대상일수 ÷ 해당월 총일수) ] ← 월 중간 전환은 일할 산식금액 = 보증금분 + 월세분 최대지원 = Σ 행 [ 120,000,000 × r × 일수/365 ] 지원금액 = min(산식금액, 최대지원) ← 월세는 합계 기준으로 상한 적용

2차 재질의

1차 답변 후에도 남은 항목입니다. 1~4번은 이번 답변에서 새로 생긴 질문이고, 5~9번은 1차 검토의 P1 항목 중 아직 답을 받지 못한 것입니다.

  1. 기준금리 입력 주체. 최초 요청은 “관리자에서 별도로 설정”, 이번 답변은 “회원 직접 입력”입니다. 관리자 등록값을 자동 적용하고 회원은 수정할 수 없게 하는 방식을 제안드리는데 괜찮을까요? 회원 입력을 유지한다면 관리자 기준금리 관리 메뉴는 필요한가요?
  2. “해당 분기”의 기준. 신청기간을 상시 열면 11월에 7~9월분을 신청할 수 있나요? 직전 분기 신청 마감일이 있나요? 퇴사 예정자의 당분기 신청(예: 10/1~퇴사일)을 허용하면 일반 직원의 당분기 조기 신청도 열리는데, 관리자 반려로 처리하면 될까요?
  3. 차수 순서와 재부여. 차수는 신청한 순서인가요, 대상기간 순서인가요? 1차수를 취소하면 2차수가 1차수로 바뀌나요? 월세→전세→월세처럼 같은 구분이 다시 나오는 경우도 차수를 나누나요?
  4. “5p” 신청서 양식 공유. 답변에 나온 5페이지(차수, 7. 최대한도 기준)가 화면설계서와 다른 문서로 보입니다. 원본을 공유해 주실 수 있을까요?
  5. 승인 시 차감(미답변). 금액은 분기 건별 상한이므로 차감하지 않겠습니다. 다만 정책의 기간 한도(매매 13년, 전·월세 합산 10년)는 시스템에서 관리해야 하나요? 관리한다면 도입 전 지원 이력은 어떻게 이관하나요?
  6. 입사 전 계약의 갱신·연장·대환대출을 “입사 이후 계약”으로 인정하나요?
  7. 실제 납입이자가 산식 금액보다 적으면 실제 이자까지만 지원하나요?
  8. 부부가 모두 임직원일 때 같은 대출·계약에 대한 중복 신청은 어떻게 막나요?
  9. 주민등록번호가 포함된 증빙(가족관계증명서·등본)은 수집 근거와 보관기간을 어떻게 정하나요? 뒷자리 마스킹 발급으로 안내해도 될까요?
