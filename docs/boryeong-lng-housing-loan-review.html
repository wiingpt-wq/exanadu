경로별 지원한도 계산

한도는 “연간 금액”으로 표현되어 있으므로, 대상기간 일수로 일할하여 매 신청 건에 적용하는 방식을 제안합니다. 기준금리가 기간 중 바뀌면 금리 구간별로 나눠 계산한 뒤 합산합니다.

공통 정의

적용금리 r = 한국은행 기준금리(관리자 등록값, 구간별) + 가산금리 1.00%p 대상기간 비율 = 구간 일수 ÷ 365 (시작일·종료일 모두 포함, 윤년도 365 고정 제안) 구간 분할 = 신청 행 기간 ∩ 기준금리 등록 기간 → 구간마다 r 이 하나 금액 처리 = 구간별 계산값은 소수 유지, 경로 합계에서 원 미만 절사

경로 ① 매매 (구분: 매입)

산식금액 = Σ 구간 [ 대출잔액 × r × 일수/365 ] 한도금액 = Σ 구간 [ 180,000,000 × r × 일수/365 ] 지원금액 = Σ 구간 [ min(대출잔액, 1.8억) × r × 일수/365 ] ← 잔액 1.8억 초과분만 잘림 기간한도 = 매매 누적 지원일수 ≤ 13년(4,748일 또는 156개월, 정의 필요)

경로 ② 전세

지원금액 = Σ 구간 [ min(대출잔액, 1.2억) × r × 일수/365 ] 기간한도 = 전세 + 월세 누적 지원일수 ≤ 10년

경로 ③ 월세 (보증금 + 월세)

보증금분 = Σ 구간 [ 보증금 × r × 일수/365 ] 월세분 = Σ 월 [ 월세 × (해당월 대상일수 ÷ 해당월 총일수) ] ← 월 중간 시작·종료는 일할 산식금액 = 보증금분 + 월세분 한도금액 = Σ 구간 [ 120,000,000 × r × 일수/365 ] 지원금액 = min(산식금액, 한도금액) ← 월세 경로는 합계 기준으로 한도 적용

경로 ②+③ 동일 기간 전세·월세 동시 존재 시

한도금액 = 1.2억 × r × 일수/365 를 전세 + 월세 합계에 1회만 적용 (권장: 동일 기간 전세·월세 동시 입력 자체를 차단. 주거지는 1곳이라는 전제)
